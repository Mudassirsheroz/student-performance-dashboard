# Students Performance Dashboard

Interactive dashboard built with Dash to visualize student performance data.

## Features

- Total students and average scores summary
- Gender distribution bar chart
- Score distribution histograms with dropdown selection
- Boxplots for scores by test preparation course status
- Scatter plot of reading vs writing scores colored by gender
